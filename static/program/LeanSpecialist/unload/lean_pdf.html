1. 目的

为了持续推进企业精益运营转型，构建一支精通精益方法论、掌握精益管理工具并具备影响力和驱动力的精益骨干与教练团队，特制定本细则。

2. 职责

2.1 总经理

负责审批精益认证意见。

2.2 精益办

2.2.1

负责精益认证的整体组织与实施，包括课程开通、理论考试组织、认证评审组织等。

2.2.2

负责认证结果备案，并将结果转人资部。

2.3 人资部

负责应用精益认证结果，将其作为职务竞聘、晋升的依据。

3. 精益认证等级与认证标准

认证等级 定位 认证标准
精益学员 熟悉精益基本理念和知识 完成精益学员课程培训，并通过理论考试
精益骨干 掌握并应用精益理念、工具和方法，参与精益项目
  1. 取得精益学员资格
  2. 完成精益骨干课程培训，并通过理论考试
  3. 参与单个精益项目6个月以上
  4. 通过精益办认证评审
精益教练 组织和领导精益项目的开展
  1. 取得精益骨干认证
  2. 作为项目举措负责人，承担至少1个公司级精益项目或2个部门级精益项目
  3. 完成至少4门精益课程的实训任务
  4. 通过精益办认证评审
资深教练 发掘精益项目、并指导精益项目的开展与实施
  1. 取得精益教练认证
  2. 作为项目举措负责人，至少领导4个公司级精益项目
  3. 完成至少8门精益课程的实训任务
  4. 通过精益办认证评审

4. 认证程序

精益认证采用个人申请、逐级申请认证的方式。

4.1 精益学员认证

精益学员是精益管理工作的储备力量，需熟悉精益基本理念和知识。认证流程如下：

4.1.1 申请学习

公司范围内有意愿的职工均可向精益办提出学习精益课程的申请，由精益办开通线上学习权限，个人安排自主学习。

4.1.2 理论考试

学完《精益课程明细表》精益学员阶段课程后，参加精益办组织的理论考试。原则上，精益办按季度组织理论考试，考试合格者即可取得精益学员资格，该资格是精益骨干认证的必备条件。

4.2 精益骨干、精益教练、资深教练认证

精益骨干、精益教练、资深教练分别作为企业精益管理的基础力量、中坚力量、引领力量，精益办每年组织两次集中认证（分别在年中、年末），具体时间以认证通知为准。认证流程如下：

4.2.1 个人申请

个人对照各等级认证标准，填写《精益认证申请表》，提交至精益办。在精益办任职6个月及以上人员参加精益认证，对精益项目经验不作要求。

4.2.2 理论考试

申请精益骨干认证人员须通过精益办组织的对应等级的理论考试，考试合格者可进入下一环节。

4.2.3 个人总结与自评

申请人编写个人总结，填写《精益认证个人自评表》，其中评分举例说明必须填写。申请精益教练、资深教练认证的人员，需同时提交完成的精益课程实训任务。

4.2.4 认证预评价

由申请人所在项目的项目举措负责人、项目关联业务的负责人、项目顾问共3 - 5人组成预评价小组。预评价小组成员按照申请人在精益项目中的行为、取得成果，从精益方法论、精益管理工具、精益影响力、精益驱动力四个维度进行预评价，填写《精益认证预评价表》。预评价结果作为答辩考察重要的参考资料。

4.2.5 认证评审

申请人参加现场答辩，评委小组由3 - 5人组成，其中麦肯锡顾问不少于1人。评委小组按照《精益认证答辩、研讨评价表》，从精益方法论、精益管理工具、精益影响力、精益驱动力四个维度进行提问，考察申请人的精益水平并打分。针对评价结果，评委小组组织专项研讨会，达成共识，形成最终认证意见。各等级认证得分要求如下：

  • 精益骨干：平均得分≥2.5分，无明显不符合项；
  • 精益教练：平均得分≥3.5分，无明显不符合项；
  • 资深教练：平均得分≥4.5分，无明显不符合项。

4.2.6 认证结果审批

精益办将精益认证意见报总经理审定，审定后将精益认证结果备案，并转人资部作为职务竞聘、晋升对应条件使用。

5. 认证结果应用

5.1 职务竞聘、晋升要求

竞聘、晋升科级职务须取得精益骨干及以上认证，竞聘、晋升中层正职（单位负责人）须取得精益教练及以上认证。具体执行日期根据公司决策确定。

5.2 精益办人员要求

精益办人员符合精益骨干认证标准，须参加认证，拒绝参加认证或连续两次认证未通过骨干认证的，返回原单位。
